CUSTOM AVATARS GUIDE
====================

You can add ANY animated .gif (or .png) file to this folder!

Examples of custom avatars:
  - charmander.gif
  - cat_walk.gif
  - mario.gif
  - sonic.gif
  - cute_dog.gif

HOW IT WORKS:
1. Simply drag & drop any .gif file into this folder.
2. Desktop Companion will automatically scan this folder every reminder interval and include your custom avatars in the dynamic avatar rotation!
3. You can access this folder at any time by right-clicking the 💧 Desktop Companion icon in your Windows System Tray and selecting "Settings".
